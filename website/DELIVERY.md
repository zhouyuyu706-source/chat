# Zova 网站与正式发布门槛

落地页：单文件 HTML，嵌入 Zova 图标及 Sora 可变字体；按用户要求直接引用远程视频／海报，不代理或本地化素材。正式域名尚未注册，免费第三方子域名只解决访问入口，不产生独占域名所有权。

## 当前可交付范围

- 中文视频落地页、平台优势、Windows／Android／iPhone 下载选择、真实发布状态。
- Windows x64 开发预览压缩包、SHA256 校验、对应源码及许可证。
- 香港服务器独立 Nginx 站点与 HTTPS，不覆盖商城站点。

## 不得宣称三端正式版已完成

- Windows：未代码签名，未完成双设备文字／图片／文件／音视频、离线重连、备份恢复及升级回滚验收。
- Android：现有源码使用 compileSdk/targetSdk 30、旧 Gradle 和原生依赖；无 SDK/NDK 构建环境、已构建 APK 或发布签名，不能以改包名代替交付。
- iOS：未获得运营方 Apple Developer 团队／签名和可用 Mac/Xcode；不能生成真实 App Store 或 TestFlight 地址。
- 基础设施：仍有原 Jami 公共引导／中继等依赖，独立部署与移动推送尚未完成。
- 安全：当前旧版依赖（包括 Qt 6.2.1、OpenSSL 1.1.1 系列等）须在生产发布前审查及升级。不要宣传绝对隐私、无服务依赖、已审计安全或未经验证的性能数字。

## 更新网站

编辑 index.template.html，运行 build.ps1 输出 public/index.html；public 仅放公开可下载文件，禁止放签名私钥、SSH 密钥、用户数据或服务凭据。

下载链接只在存在对应安装包、签名或发布渠道并完成验收后启用。不得链接到原版 Jami 冒充 Zova，不得用网页快捷方式冒充原生手机应用。
