# Zova 0.2.3 Windows 界面更新

按用户提供的 Jami 界面参考恢复深色欢迎页、双入口、圆角按钮、底部账户栏和主页提示区域；保留 Zova 名称与自有服务默认配置。

- 移除欢迎页的黑底品牌横幅，采用透明蓝色图形与原生 Zova 字标。
- 原有设备关联、备份恢复、会议、SIP 与账户管理入口保留；后两类入口位于高级功能下。
- 开发者名单不再默认展示，仍可从关于页的“开源许可与贡献者”查看。许可证、版权与对应源码保留。
- 更新首次启动切换为深色模式，之后仍可从设置选择浅色；账号、消息与网络配置不迁移、不删除。
- 本次仅更新 Windows。安卓继续提供 0.2.2，iOS 显示正在构建中。

说明：这是在既有 Qt 客户端上的布局适配，并非更换为参考截图对应的新版 Jami 全部代码，也不代表每个设置页与截图逐像素一致。Windows 安装包仍未受信任代码签名。原 0.2.2 关于公开 DHT、noPush、免费子域名及未完成全功能/安全验收的限制继续适用。

图片处理使用内置 imagegen，提示为：保留蓝色折带 Z 图形，去除背景，生成透明应用标志。界面只取蓝色图形，Zova 字标由界面文本渲染；项目资源位于 client-qt/resources/images/zova-transparent.png。
