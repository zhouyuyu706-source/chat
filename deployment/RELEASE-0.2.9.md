# Zova Windows 0.2.9

## 本版变化

- 首页恢复为聊天软件的功能型空状态，移除大 Logo、宣传口号、光晕背景和身份卡片。
- 保留并简化添加联系人、复制识别码、显示二维码、账户与设备入口。
- 左侧空状态去掉重复的胶囊按钮，统一侧栏和账户区域的圆角与层级。
- 主操作使用克制的单一品牌色，交互仍有悬停、按下和键盘焦点反馈。

## 验证

- Windows x64 Release 编译通过。
- 实际启动并检查深色界面布局。
- 已验证“添加联系人”会把输入焦点送入搜索框。
- 控件自动化树可识别添加联系人、复制识别码、显示二维码和账户与设备入口。

## 已知限制

- Windows 安装包尚无受信任代码签名。
- 安卓仍为 0.2.2；iPhone 版本尚未发布。
- 双设备跨网络通信和安全审计不声明已完成。
