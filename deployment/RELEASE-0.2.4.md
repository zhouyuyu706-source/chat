# Zova 0.2.4 — Windows 界面与交互

- 移除顶部独立黑色横条，改为透明悬浮的最小化、最大化/还原、关闭按钮。顶部中央仍可拖动窗口。
- 深色环境光背景，侧栏与卡片细腻边缘、柔和阴影；卡片有短暂悬停透视与点击反馈，没有持续动画。
- 首页卡片增加实际操作：添加联系人、显示邀请二维码、账户与设备。
- 复制识别码后显示“已复制识别码”，随后自动恢复。
- 原账号、消息、服务器默认配置和开源声明均保留。

本次仅更新 Windows，安卓仍为 0.2.2；iOS 正在构建中。界面验收不等于完成通信或安全验收；Windows 安装包仍未受信任代码签名，其他 0.2.2/0.2.3 限制继续适用。
