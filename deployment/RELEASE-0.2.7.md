# Zova Windows 0.2.7

本版聚焦桌面交互，而非增加装饰。

- 首页去掉宣传口号、重复功能卡片和悬停倾斜，保留品牌、识别码及常用操作。小窗口可滚动，复制后有确认反馈，识别码可选中。
- 二维码有明确关闭按钮、Esc关闭、返回原焦点、加载和重试状态。
- “账户与设备”进入当前账户设置，不再跳到新账户向导。
- 窗口控制与聊天、通话及设置操作分开，窄窗口也保留顶部安全区，没有恢复黑色标题条。
- 搜索聚焦选中旧输入，清空后保持焦点，Esc优先清空；隐藏搜索框不截获Ctrl+F。
- 按钮区分悬停、按下、键盘焦点和禁用状态；图标按钮补齐可访问名称。主按钮调整文字对比度。
- 修正设置菜单的翻译上下文；不恢复“关于 Zova”入口。

原账号、通信服务、开源版权及许可证均保留。仅 Windows 更新，Android 仍为0.2.2，苹果端仍待构建。安装包未代码签名。本版不代表跨设备通信或安全审计全部通过。

实际启动、主页、二维码打开、账户设置路由已检查。部分真实窗口输入被用户输入保护中止，未将无法执行的步骤记为通过。按钮离线测试与检查范围参见 UI-AUDIT-0.2.7.md。
