# Zova Windows 交互精修审查

## 方向与范围

按“网站超级美化”技能先审查后修改。现有产品是 Qt 桌面通讯软件，不是网站落地页；保留 Zova 品牌、左侧会话和底部账号、原通信能力及深浅主题。DESIGN_VARIANCE 4 / MOTION_INTENSITY 3 / VISUAL_DENSITY 4。Qt 原生控件延续现有体系，不迁移到 Web 框架。官网只更新版本下载，不重做落地页。

## 修改前

- 冷色深色底、微软雅黑界面、蓝色 Z 图标与 Segoe UI 字标。
- 大标题宣传口号和三张等高功能卡片，首页重复展示营销描述。
- 二维码无关闭按钮及加载失败反馈，Esc 与全局快捷键竞争。
- “账户与设备”却打开添加账号向导。
- 窗口按钮的透明拖动层与聊天头部操作区域重叠。
- 按钮悬停优先于按下，纯图标按钮可访问名称为空；搜索清空和再进入的焦点不完整。

## 修改后

- 首页使用直白操作说明、可选中的识别码、复制反馈与二维码按钮；联系人及账户采用轻量操作行。
- 使用单一蓝色强调、12/14px圆角体系；仅100至140ms的按下/颜色反馈，无循环动画、无额外视觉素材或依赖。
- 二维码统一为模态弹窗，有标题、32px关闭目标、Esc及遮罩关闭、原入口焦点恢复、加载及重试状态。
- 当前账户设置使用明确路由；聊天、设置、窄窗和向导给窗口控制留出36px安全区域。顶部没有黑条。
- 搜索快捷键仅可见时有效，聚焦选中旧输入，清空后仍可输入，Esc先清空查询。
- 通用按钮补禁用态、键盘焦点、图标名称、Enter按下和松开单次激活。

## 预检适用性

品牌、用户数据、服务器、版权和导航名称保留。新版不恢复“关于 Zova”。原有品牌素材复用，不生成无关照片。首页无营销口号、三列卡片、虚构统计、装饰性标签或文字渐变。网页SEO/首屏图片/Lighthouse/React/GSAP项目不适用于原生客户端，未声称网页性能验收。

本次不包含安卓界面升级、双设备通话或完整安全审计。实际测试结果见本版发布说明。

## 实测补记

- QML语法解析及Windows构建通过。最终程序启动不再有新增的Flickable绑定循环或旧AboutPopUp绑定循环；仍有原项目QQuickWidget/OpenGL提示，不能声称零警告。
- 实机确认新首页与无“关于”入口，二维码可打开，“账户与设备”确实进入当前账号与关联设备页面。部分后续点击/键盘步骤被用户输入保护中止，未记通过。
- 主按钮白字对比度：正常5.69:1、悬停6.84:1、按下8.56:1；深色正文8.14:1、浅色正文5.51:1；复制按钮深色8.58:1、浅色6.46:1。基于所用颜色的WCAG公式计算，不等同于整屏无障碍审计。
- 直接加载生产QML的离线测试最终为23行为用例加初始化/清理共25通过，0失败；包含两通用按钮19项和QuickAction深浅主题、尺寸、键盘及禁用态4项。测试仅替换后端主题/屏幕上下文，不重写待测按钮逻辑。离屏字体及QQmlContext调试提示保留，不是完整截图/读屏器验收。
- 整个客户端浅色界面、完整窗口缩放、通话覆盖及跨设备链路尚未全部实机回归；不宣称软件所有界面全部验收。
